# BBANG PDF — 다운로드

**BBANG PDF** — 가족용 PDF 열람·편집 프로그램 (모든 처리는 내 컴퓨터에서만) · 문의: jdent0228@gmail.com

BBANG PDF(구 "PDF 편집기 / PDF Edit by Dr.J") 설치 파일 배포 페이지입니다. 모든 처리가 내 컴퓨터 안에서만 일어나며, **PDF 파일은 어떤 서버로도 전송되지 않습니다.**

## 다운로드

👉 **[최신 버전 다운로드](https://github.com/jdent0228/pdfedit-releases/releases/latest)**

| 운영체제 | 파일 |
|---|---|
| macOS (Apple Silicon) | `BBANG-PDF-x.y.z-arm64.dmg` |
| Windows (64비트) | `BBANG-PDF-Setup-x.y.z.exe` |

최초 실행 시 비밀번호가 필요합니다 (문의 메일로 요청). 한 번 통과하면 다시 묻지 않습니다.

## 설치 방법

**macOS**: dmg를 열고 앱을 응용 프로그램 폴더로 드래그. Apple 개발자 서명이 없는 앱이라 **처음 실행할 때 "손상되었기 때문에 열 수 없습니다" 경고**가 뜹니다 — 실제 손상이 아니라 macOS의 미서명 앱 차단입니다. **터미널을 열고 아래 한 줄을 붙여넣어 실행**하면 해결됩니다 (최초 1회만, 이후 자동 업데이트는 이 절차가 필요 없습니다):

```
xattr -cr "/Applications/BBANG PDF.app"
```

구 버전(`PDF Edit by Dr.J.app`)을 쓰고 있었다면 앱 안의 자동 업데이트로 그대로 올라갑니다. 이 경우 앱 폴더의 이름은 옛 이름으로 남지만 표시 이름과 기능은 BBANG PDF입니다.

**Windows**: Setup.exe 실행(클릭 한 번으로 설치). "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**. 구 버전은 앱 안의 자동 업데이트(바뀐 부분만 다운로드)로 갱신됩니다.

## 기본 PDF 뷰어로 지정

- **macOS**: 아무 PDF 파일 우클릭 → 정보 가져오기 → "다음으로 열기"에서 이 앱 선택 → **모두 변경**
- **Windows**: 설정 → 앱 → 기본 앱 → `.pdf` → 이 앱 선택
